# Avalonia Tizen

## About

Adds support for the Samsung Tizen platform to [Avalonia](https://github.com/AvaloniaUI/Avalonia).  

## Status

This project was previously part of the [Avalonia main repository](https://github.com/AvaloniaUI/Avalonia).  
It now lives in its [own repository](https://github.com/AvaloniaUI/Avalonia.Tizen).
